# 🛒 Digital Tools Buying Website
## 📖 Description
A modern and responsive digital tools marketplace where users can explore and purchase various digital products such as AI tools, design templates, and automation kits.

This project includes a dynamic cart system, product toggling feature, and real-time user notifications to enhance the overall user experience.
## ⚙️ Technologies Used  
- React.js  
- Tailwind CSS  
- DaisyUI  
- JavaScript (ES6+)  
- React-Toastify  
- JSON (Product Data)  

## ✨ Features
### 🛍️ Dynamic Cart System 
Users can add and remove products from the cart with real-time updates.
### 🔄 Product & Cart Toggle
Easily switch between product list and cart view.
### 🔔 Toast Notifications
Alerts for add to cart, remove item, and checkout using React-Toastify.
